# 息眠 · Mac Sleep Control

轻量、中文、原生的 Mac 息屏与睡眠时间控制工具。使用 SwiftUI 和 macOS 自带的电源管理能力，无第三方运行依赖。

## 功能

- 分别设置**显示器息屏**和**电脑自动睡眠**的闲置时间：1–1440 分钟，或永不。
- 支持按接通电源、使用电池、UPS 分别设置；只显示当前 Mac 具有的电源类型。
- 省电、日常、仅息屏、始终开启四个快捷方案。
- 首次应用前自动保存原设置，之后可恢复备份中的各电源类型。
- 临时保持唤醒 30 分钟、1 小时、2 小时或直到退出，可选屏幕常亮。
- 菜单栏快捷入口、立即息屏、立即睡眠，以及查看当前防睡眠活动。
- 应用设置后重新读取系统并核对，明确报告授权取消、写入失败和系统返回值不一致。

## 下载与使用

从本仓库的 Releases 下载 `MacSleepControl-1.0.0-macOS.zip`，解压后将 **息眠.app** 拖入“应用程序”，双击打开。兼容 **macOS 14 或更新版本，Apple Silicon 和 Intel**。

1. 选择电源类型，输入时间或打开“永不”开关。
2. 点击“应用设置”。macOS 会弹出管理员授权窗口，密码由系统处理，应用不会读取或保存密码。
3. 成功后，卡片中的“当前”显示系统实际值。设置会在应用退出后保留。
4. 临时保持唤醒无需管理员权限，到期或退出应用后结束。关闭主窗口后可从菜单栏重新打开；使用 `⌘Q` 完全退出。

发布包使用本地临时签名（ad-hoc），尚无 Apple Developer ID 签名或公证。下载后 macOS 可能阻止首次打开；确认来自自己的仓库后，可到“系统设置 → 隐私与安全性”查看打开选项，也可用下方命令自行编译。

## 时间的含义

这里设置的是**无用户操作后的自动休息时间**，不是指定钟点，也不是倒计时强制关机。息屏和睡眠均由系统管理，睡眠时间不是“息屏后再等多少分钟”。电脑进入睡眠时屏幕也会关闭。

媒体播放、下载工具、共享服务、外接设备及其他电源断言可能推迟自动睡眠。点击“查看防睡眠活动”可以检查 macOS 的实时记录。临时保持唤醒用于阻止闲置睡眠，不会改变合盖、低电量或用户手动睡眠等系统行为。

应用仅修改 `pmset` 的 `displaysleep` 和 `sleep` 两个键，不调整休眠模式、磁盘休眠、网络唤醒或屏幕锁定。临时保持唤醒通过 IOKit 电源断言实现；应用进程退出或崩溃时，系统会释放其断言。

## 本地构建

需要 macOS、Xcode Command Line Tools 和 Swift 6 或更新版本。无需安装完整 Xcode。

```bash
xcode-select --install  # 已安装则跳过
bash scripts/test.sh
bash scripts/build.sh
open dist/息眠.app
```

默认同时编译 arm64 和 x86_64 并合成 Universal 应用；`UNIVERSAL=0 bash scripts/build.sh` 可仅构建 Apple Silicon。构建产物与 ZIP 位于 `dist/`，`SHA256SUMS.txt` 用于校验下载完整性。

## 备份与隐私

原设置保存在本机 `~/Library/Application Support/MacSleepControl/original-settings.json`，包含时间、电源类型及备份日期。备份在首次尝试应用前创建，后续不覆盖；恢复按钮恢复这份原设置。取消管理员授权不会提交新的时间。

应用不连接网络、不收集数据、不自动启动、不安装后台服务，也不保存管理员密码。源码和发布包不包含用户的本机电源设置或系统诊断日志。

## 验证范围

自动验证覆盖系统输出解析、电源类型隔离、参数范围、管理员脚本构造、备份序列化和本机只读设置获取。已在 Apple Silicon Mac 实测窗口、快捷方案、非法输入保护、临时防睡眠断言的创建与释放、诊断面板。发布构建包含两个架构，并检查应用签名；Intel 架构已交叉编译，未在 Intel 硬件实测。实际自动睡眠受系统和其他应用活动影响，修改时间的授权与真实息屏/睡眠需在使用时验证。
